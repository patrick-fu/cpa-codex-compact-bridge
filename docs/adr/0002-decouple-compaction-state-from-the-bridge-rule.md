# Normalize bridge compaction state for every target and fail closed on unreadable state

Replay of the plugin's own `cpa_compact_*` plaintext state is decoupled from the Bridge Rule so that a session compacted on a Bridged Compact Route can continue, at summary level, on a Native Compact Route without pulling that model's future compact turns into the facade. Reasoning state stays out of scope: only the `compaction` item type is read, and a `reasoning` item is never rewritten or migrated. Opaque native compaction state is forwarded only when the requested model explicitly matches a `passthrough` rule; this rule is an administrator-declared compatibility boundary because the plugin cannot verify which provider created opaque state, while an unmatched model is not trusted merely because CPA's fallback is passthrough. Mixed state, unmatched opaque state, and plaintext state with blank `encrypted_content` are rejected with the non-retryable client code `invalid_compaction_state` (HTTP 400) before any upstream call. Generation keeps the existing retryable `compact_bridge_failed` contract and refuses to persist a blank summary.
